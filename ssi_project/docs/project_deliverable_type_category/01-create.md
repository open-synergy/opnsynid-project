# Create Deliverable Type Category

> **Module:** `ssi_project`\
> **Model:** `project_deliverable_type_category`\
> **Menu:** Project > Configuration > Project > Deliverable Type Categories\
> **Actor:** user in group _Project Deliverable Type Category_

## Pre-Condition

- **Access:** User is in group _Project Deliverable Type Category_.

## Flow

1. Open the **Project > Configuration > Project > Deliverable Type Categories** menu.
2. Click the **New** button. **(14.0: "Create")**
3. Fill in the required fields:
   - **Name** _(required)_: Enter the name of the deliverable type category.
   - **Code** _(required)_: Enter a unique code, or click **Generate Code** in the form
     header to fill it from the configured sequence.
4. Click **Save**.

## Post-Condition

- A new deliverable type category is created and is listed in **Deliverable Type
  Categories**.
