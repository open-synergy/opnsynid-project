# Deactivate Deliverable Type Category

> **Module:** `ssi_project`\
> **Model:** `project_deliverable_type_category`\
> **Menu:** Project > Configuration > Project > Deliverable Type Categories\
> **Actor:** user in group _Project Deliverable Type Category_\
> **Active:** `true` → `false`\
> **Requires:** `01-create`

## Pre-Condition

- **Record:** The record is currently active.
- **Access:** User is in group _Project Deliverable Type Category_.

## Flow

1. Open the **Project > Configuration > Project > Deliverable Type Categories** menu.
2. Find and open the record to deactivate.
3. Click the **Action** menu, then click **Archive**.
4. Click **OK** on the confirmation dialog.

## Post-Condition

- The record is archived and no longer appears in the default Deliverable Type
  Categories list.
