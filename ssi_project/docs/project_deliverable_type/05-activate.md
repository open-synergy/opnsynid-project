# Activate Deliverable Type

> **Module:** `ssi_project`\
> **Model:** `project_deliverable_type`\
> **Menu:** Project > Configuration > Project > Deliverable Types\
> **Actor:** user in group _Project Deliverable Type_\
> **Active:** `false` → `true`\
> **Requires:** `04-deactivate`

## Pre-Condition

- **Record:** The record is currently archived.
- **Access:** User is in group _Project Deliverable Type_.

## Flow

1. Open the **Project > Configuration > Project > Deliverable Types** menu.
2. Enable the **Archived** filter in the search bar.
3. Find and open the record to reactivate.
4. Click the **Action** menu, then click **Unarchive**.

## Post-Condition

- The record is restored and appears again in the default Deliverable Types list.
