# Deactivate Deliverable Type

> **Module:** `ssi_project`\
> **Model:** `project_deliverable_type`\
> **Menu:** Project > Configuration > Project > Deliverable Types\
> **Actor:** user in group _Project Deliverable Type_\
> **Active:** `true` → `false`\
> **Requires:** `01-create`

## Pre-Condition

- **Record:** The record is currently active.
- **Access:** User is in group _Project Deliverable Type_.

## Flow

1. Open the **Project > Configuration > Project > Deliverable Types** menu.
2. Find and open the record to deactivate.
3. Click the **Action** menu, then click **Archive**.
4. Click **OK** on the confirmation dialog.

## Post-Condition

- The record is archived and no longer appears in the default Deliverable Types list.
