# Delete Deliverable Type

> **Module:** `ssi_project`\
> **Model:** `project_deliverable_type`\
> **Menu:** Project > Configuration > Project > Deliverable Types\
> **Actor:** user in group _Project Deliverable Type_\
> **Requires:** `01-create`

## Pre-Condition

- **Record:** The record is not archived.
- **Access:** User is in group _Project Deliverable Type_.

## Flow

1. Open the **Project > Configuration > Project > Deliverable Types** menu.
2. Find and open the record to delete.
3. Click the **Action** menu, then click **Delete**.
4. Click **OK** on the confirmation dialog.

## Post-Condition

- The record is removed from the Deliverable Types list.
