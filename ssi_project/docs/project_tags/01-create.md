# Create Project Tag

> **Module:** `ssi_project`\
> **Model:** `project.tags`\
> **Menu:** Project > Configuration > Project > Tags\
> **Actor:** user in group _Project Tag_

## Pre-Condition

- **Access:** User is in group _Project Tag_.

## Flow

1. Open the **Project > Configuration > Project > Tags** menu.
2. Click the **New** button. **(14.0: "Create")** An editable row is added at the bottom
   of the list.
3. Fill in the required fields in the new row:
   - **Name** _(required)_: Enter the name of the tag.
4. Click the **Save** button of the list.

## Post-Condition

- A new tag is created and is listed in **Tags**.
