# Edit Project Tag

> **Module:** `ssi_project`\
> **Model:** `project.tags`\
> **Menu:** Project > Configuration > Project > Tags\
> **Actor:** user in group _Project Tag_\
> **Requires:** `01-create`

## Pre-Condition

- **Access:** User is in group _Project Tag_.

## Flow

1. Open the **Project > Configuration > Project > Tags** menu.
2. Find and open the record to edit.
3. Click the **Edit** button.
4. Change the required fields, for example **Name** or **Color**.
5. Click **Save**.

## Post-Condition

- The record is updated with the new values.
