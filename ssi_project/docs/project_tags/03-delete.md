# Delete Project Tag

> **Module:** `ssi_project`\
> **Model:** `project.tags`\
> **Menu:** Project > Configuration > Project > Tags\
> **Actor:** user in group _Project Tag_\
> **Requires:** `01-create`

## Pre-Condition

- **Access:** User is in group _Project Tag_.

## Flow

1. Open the **Project > Configuration > Project > Tags** menu.
2. Find and open the record to delete.
3. Click the **Action** menu, then click **Delete**.
4. Click **OK** on the confirmation dialog.

## Post-Condition

- The record is removed from the Tags list.
- The tag is removed from every project and task that used it.
