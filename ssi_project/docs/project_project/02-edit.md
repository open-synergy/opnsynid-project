# Edit Project

> **Module:** `ssi_project`\
> **Model:** `project.project`\
> **Menu:** Project > Projects\
> **Actor:** user in group _Project User_ (or _Project Validator_)\
> **Requires:** `01-create`

## Pre-Condition

- **Record:** Status is **New**.
- **Access:** User is in group _Project User_ (or _Project Validator_).

## Flow

1. Open the **Project > Projects** menu.
2. Find and open the record to edit.
3. Click the **Edit** button.
4. Change the required fields, for example **Project Name**, **Customer**, or the
   **Units** on the **Settings** tab.
5. Click **Save**.

## Post-Condition

- The record is updated with the new values.
