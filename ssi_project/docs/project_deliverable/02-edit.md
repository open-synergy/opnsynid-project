# Edit Project Deliverable

> **Module:** `ssi_project`\
> **Model:** `project_deliverable`\
> **Menu:** Project > Project > Deliverables\
> **Actor:** user in group _Project Deliverable User_\
> **Requires:** `01-create`

## Pre-Condition

- **Record:** Status is **Draft**.
- **Access:** User is in group _Project Deliverable User_ (or _Project Deliverable
  Validator_).

## Flow

1. Open the **Project > Project > Deliverables** menu.
2. Find and open the record to edit.
3. Click the **Edit** button.
4. Change the required fields:
   - **Title**: Change the title of the deliverable.
   - **Date Due**: Change the due date of the deliverable.
5. Click **Save**.

## Post-Condition

- The record is updated with the new values.
