# Edit Project Phase

> **Module:** `ssi_project`\
> **Model:** `project_phase`\
> **Menu:** Project > Project > Phases\
> **Actor:** user in group _Project Phase User_\
> **Requires:** `01-create`

## Pre-Condition

- **Record:** Status is **Draft**.
- **Access:** User is in group _Project Phase User_ (or _Project Phase Validator_).

## Flow

1. Open the **Project > Project > Phases** menu.
2. Find and open the record to edit.
3. Click the **Edit** button.
4. Change the required fields:
   - **Title**: Change the title of the phase.
   - **Date Due**: Change the due date of the phase.
5. Click **Save**.

## Post-Condition

- The record is updated with the new values.
