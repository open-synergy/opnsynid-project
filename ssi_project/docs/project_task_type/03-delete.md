# Delete Task Stage

> **Module:** `ssi_project`\
> **Model:** `project.task.type`\
> **Menu:** Project > Configuration > Project > Stages\
> **Actor:** user in group _Project Stage_\
> **Requires:** `01-create`

## Pre-Condition

- **Record:** The stage is not archived.
- **Access:** User is in group _Project Stage_.

## Flow

1. Open the **Project > Configuration > Project > Stages** menu.
2. Find and open the record to delete.
3. Click the **Action** menu, then click **Delete**.
4. Click **OK** on the confirmation dialog.

## Post-Condition

- The record is removed from the Stages list.
